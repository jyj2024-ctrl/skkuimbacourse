# SKKU IMBA 2026-2학기 과목 비교 사이트 설계

## 목적
IMBA 2026년 2학기 30개 과목(그룹 A~F, 전공기반/전공심화)에 대한 교수/난이도/학생의견/강의계획서 요약 정보를 한눈에 비교할 수 있는 정적 웹페이지. 학생이 그룹별로 과목을 훑어보고, 관심 있는 과목들을 체크박스로 선택해 항목별 비교표를 볼 수 있도록 한다. 같은 그룹은 시간표상 동시 수강이 불가하므로 이를 시각적으로 안내한다.

## 기술 스택
빌드 도구 없는 순수 정적 사이트.

```
index.html   페이지 구조
style.css    스타일
script.js    필터/검색/체크박스/비교/모달 로직
data.js      과목 데이터 (30개 과목 객체 배열, 하드코딩)
```

브라우저에서 index.html을 직접 열거나 GitHub Pages 등에 그대로 배포 가능해야 한다. 외부 의존성은 Pretendard 폰트 CDN 한 가지만 사용한다.

## 데이터 모델

```js
{
  id: "kebab-case-id",
  group: "A" | "B" | "C" | "D" | "E" | "F",
  track: "전공기반" | "전공심화",
  name: "과목명",
  professor: "교수명",
  difficulty: "상" | "중" | "하" | "신규과목",
  studentOpinion: "학생 의견 원문",
  syllabus: null | {
    method: "강의방식",
    objective: "수업목표/개요",
    evaluation: "평가방법",
    curriculum: "주차별 커리큘럼",
    textbook: "교재/참고자료",
    note: "비고" // 있는 경우만
  }
}
```

### 데이터 출처 및 병합 규칙
- `그룹/구분/교수/난이도/학생의견`은 `SKKU_IMBA_2026_2학기_과목비교표.xlsx`의 `Sheet1`(= `과목별 의견.xlsx`와 동일 데이터, 30행)에서 가져온다.
- `syllabus`는 같은 파일의 `과목 비교표` 시트(22개 과목)에서 가져와 과목명으로 매칭한다. 매칭 시 다음을 정규화한다:
  - 괄호 학기 표기 제거: `(26년 1학기용)`, `(26년1학기용)` 등
  - 공백/오탈자 보정: `재무의이해 ` ↔ `재무의이해`, `회계와비즈니스모델의 이해` ↔ `회계와비즈니스모델의이해`, `글로벌비지니스협상론` ↔ `글로벌비스니스협상론`
  - 분반 표기(`(1분반)`, `(2분반)`)는 과목 식별자의 일부이므로 유지
- 아래 8개 과목은 강의계획서 시트에 없으므로 `syllabus: null`로 두고 UI에서 "수업계획서 미제출 (교수님 미등록)"으로 표시한다:
  경영자를위한데이터분석및통계적 사고, 유통관리론, 마케팅믹스론, 국제경영론, 증권투자의이해, 조직행동론, 최신정보시스템사례와전략, 글로벌금융시장
- `경영전략론`, `재무회계론`, `창업실무론`은 강의계획서가 "26년 1학기용" 기반이므로 `syllabus.note`에 "26년 1학기 계획서 기반이므로 실제와 다를 수 있음"을 유지해 모달/비교표에 노출한다.

## 페이지 구조 & 컴포넌트

1. **헤더**: 로고("S" 마크 + "SKKU IMBA 과목비교"), 부제, "같은 그룹 과목은 동시 수강이 불가합니다" 안내 배지
2. **검색/필터 바**: 과목명·교수명 검색 입력, 구분 토글(전체/전공기반/전공심화), 난이도 토글(전체/상/중/하). 필터·검색은 그룹 섹션 전체에 실시간 적용되며, 필터링되어 과목이 0개인 그룹 섹션은 숨긴다.
3. **그룹 섹션 (A~F 순서)**: 그룹 헤딩(그룹명 + 그룹 컬러 배지 + 그룹 내 과목 수) + 반응형 카드 그리드(데스크톱 3열 / 태블릿 2열 / 모바일 1열)
4. **과목 카드**: 좌상단 체크박스, 과목명, 교수명, 난이도 배지, 구분 배지, 학생의견 2줄 미리보기(말줄임), 카드 클릭(체크박스 제외 영역) 시 상세 모달 오픈
5. **상세 모달**: 과목명/교수/그룹/난이도/구분, 학생의견 전문, 강의계획서 요약 전체 항목(없으면 안내 문구), 모달 안에도 비교 선택 체크박스 제공
6. **하단 고정 비교 바**: 1개 이상 체크 시 나타남. "N개 과목 선택됨" + 선택 과목 칩(칩 클릭 시 선택 해제) + "비교하기" 버튼 + "초기화" 버튼. 같은 그룹 2개 이상 선택 시 바 안에 "⚠ 그룹 A 과목 2개 동시 선택됨" 경고 텍스트 표시(선택은 막지 않음).
7. **비교 섹션**: "비교하기" 클릭 시 부드럽게 스크롤 이동. 항목별(행: 그룹/구분/교수/난이도/학생의견/강의방식/수업목표/평가방법/주차별커리큘럼/교재/비고) × 선택 과목(열) 테이블. 같은 그룹에 속한 열들은 헤더에 그룹 경고 배지 표시, 테이블 상단에 그룹 충돌 안내 배너. 모바일에서는 테이블을 가로 스크롤 컨테이너로 감싼다. 선택 과목이 없으면 이 섹션은 비표시.

## 인터랙션 요약
- 체크박스 상태는 `script.js` 내 `Set`으로 관리, DOM은 상태 변경 시마다 다시 렌더링
- 검색/필터는 각각 독립적으로 AND 조건으로 결합
- 모달은 배경 클릭 또는 ESC로 닫힘
- 하단 바와 비교 섹션은 같은 선택 상태를 공유(단일 소스)

## 비주얼 디자인
레퍼런스(`reference/design1~4.png`, ZenCrypto 스타일)를 따른다.

- **컬러**: 배경 세이지 그린(`#C9CFA9` 계열), 카드 화이트, 포인트 라임/차트리스 옐로우그린(`#D8F24C` 계열, CTA·활성 필터·강조에 사용), 텍스트 블랙에 가까운 톤(`#161616`)
- **난이도 배지**: 상=레드 계열, 중=오렌지/옐로우 계열, 하=그린 계열, 신규과목=그레이+라임 아웃라인
- **그룹 배지**: A~F 각각 파스텔 톤 6종으로 구분
- **타이포그래피**: Pretendard(CDN), 헤드라인 굵게 / 본문 레귤러
- **카드/버튼**: 카드 큰 라운드(~20px) + 옅은 그림자 + 호버 시 리프트, 버튼/배지는 필(pill) 형태(블랙 배경/화이트 텍스트 또는 라임 배경/블랙 텍스트)
- **반응형**: 그룹 카드 그리드 데스크톱 3열 → 태블릿 2열 → 모바일 1열, 비교 테이블은 모바일에서 가로 스크롤

## 테스트/검증
- 30개 과목이 모두 정확한 그룹 섹션에 노출되는지 육안 확인
- 22개 과목 모달에 강의계획서 요약이 표시되고, 8개 과목은 미제출 안내가 표시되는지 확인
- 검색/필터 조합이 올바르게 동작하는지 확인 (예: "재무" 검색 + 난이도 "상" 필터)
- 같은 그룹 2개 이상 체크 시 경고가 하단 바와 비교 섹션 모두에 뜨는지 확인
- 비교 테이블에 다수 과목(5개 이상) 선택 시 가로 스크롤이 정상 동작하는지 확인
- 데스크톱/태블릿/모바일 너비에서 레이아웃 확인
